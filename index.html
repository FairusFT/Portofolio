// SECTION_05 — JEJAK

        
Jejak Langkah.

        
Dari deteksi wajah pertama sampai agent yang bisa di-chat dari mana saja.

      

      

        
01 — FIRST LIGHT
Face detection pertama jalan
Webcam laptop menangkap wajah, model mulai mendeteksi. Titik awal perjalanan computer vision.

        
02 — OBJECTS, FOUND
Object detection menyusul
Komputer mulai "mengerti" benda, bukan cuma wajah.

        
03 — CAMERA GOES WIRELESS
ESP32-CAM terhubung ke web
Kamera mungil tersambung ke web buatan sendiri — atur & pantau langsung dari browser.

        
04 — YOLO ERA
Naik kelas dengan YOLOv8
Deteksi objek modern yang cepat, akurat, dan lebih serius.

        
05 — HANDS ON
Hand detection via HuggingFace
Eksplorasi ekosistem model open-source — tangan terdeteksi real-time.

        
06 — AGENT ORIGINS
Agent pertama dengan Google ADK
Belajar membangun agent AI utuh: instruksi, tools, eksekusi.

        
07 — FULL CIRCLE
Hermes × Telegram × 9Router
Semua tersambung: agent yang bisa dihubungi lewat chat, jalan 24/7 di VPS.
